# Maktab_Diary

**Maktab_Diary** হলো তরিকায়ে তালীম ও মুয়াল্লিম প্রশিক্ষণ নির্দেশিকা অনুসরণ করে তৈরি একটি ডিজিটাল প্ল্যাটফর্ম। এটি শিশুদের আরবি শিক্ষা ও পাঠদানকে আকর্ষণীয় করে তোলে। এতে ওস্তাদ-ছাত্র ডায়লগ, বোর্ড ওয়ার্ক ও ধাপভিত্তিক পাঠদানের সুব্যবস্থা রয়েছে।

---

## 🏷️ ট্যাগ পার্সার নির্দেশিকা ও ব্যবহারবিধি

এই প্রজেক্টের কন্টেন্ট প্রসেস করার জন্য একটি ডেডিকেটেড `TagParser` রয়েছে[cite: 1]। নিচে প্রতিটি ট্যাগের সঠিক ব্যবহার এবং আউটপুট ডিজাইনের বিস্তারিত দেওয়া হলো:

### ট্যাগের বিবরণ ও কাজ

| ট্যাগ (শর্টকাটসহ) | কাজ / বর্ণনা | ডিজাইন ও রেন্ডারিং আউটপুট |
| :--- | :--- | :--- |
| **`[title]` / `[t]`** | মূল পাঠ বা অধ্যায়ের শিরোনাম নির্ধারণ করে[cite: 1]। | বড় হেডার (`<h2>`) হিসেবে পেজে রেন্ডার হয়[cite: 1]। |
| **`[section]` / `[sec]` / `[s]`** | সাব-টপিক বা নতুন সেকশন তৈরি করে[cite: 1]। | এটি স্বয়ংক্রিয়ভাবে একটি ইউনিক আইডি (`sec-xxxxx`) জেনারেট করে এবং রাইট সাইডবারের কুইক ইনডেক্স মেনুতে লিংক হিসেবে যুক্ত হয়ে যায়[cite: 1]। |
| **`[method]` / `[mthd]` / `[m]`** | শিক্ষণ পদ্ধতি বা মেথড বোঝাতে ব্যবহৃত হয়[cite: 1]। | কমলা রঙের লেফট বর্ডারসহ হাইলাইটেড হেডার (`<h4>`) আকারে দেখায়[cite: 1]। |
| **`[lesson]` / `[les]` / `[l]`** | মূল লেসন বা পড়াশোনার কন্টেন্ট প্রদর্শন করে[cite: 1]। | সুন্দর একটি বক্সের (`lesson-box`) মধ্যে কন্টেন্ট রেন্ডার হয়[cite: 1]। |
| **`[teacher]` / `[teach]` / `[tchr]`** | ওস্তাদের কথা বা ডায়লগ বোঝাতে ব্যবহৃত হয়[cite: 1]। | `🟢 ওস্তাদ:` ট্যাগসহ স্পেশাল মেসেজ বাবল আকারে রেন্ডার হয়[cite: 1]। |
| **`[student]` / `[stud]` / `[std]`** | ছাত্রদের উত্তর বা পারস্পরিক ডায়লগ বোঝায়[cite: 1]। | `🟡 ছাত্ররা:` ট্যাগসহ মেসেজ বাবল আকারে রেন্ডার হয়[cite: 1]। |
| **`[board]` / `[brd]` / `[b]`** | বোর্ড ওয়ার্ক বা আরবি হরফ লেখার জন্য ব্যবহৃত হয়[cite: 1]। | ডার্ক ব্যাকগ্রাউন্ডের চকবোর্ড স্টাইল বক্সে আরবি ফন্টে রেন্ডার হয়[cite: 1]। |
| **`[note]` / `[tip]` / `[n]`** | শিক্ষকের বিশেষ দিকনির্দেশনা বা টিপস দিতে ব্যবহৃত হয়[cite: 1]। | `📜 শিক্ষক নির্দেশিকা:` লেবেলযুক্ত ইন্সট্রাক্টর নোট বক্সে দেখায়[cite: 1]। |
| **`[step]` / `[stp]`** | শিক্ষাদানের ধাপে ধাপে নির্দেশ (Step-by-step) দিতে ব্যবহৃত হয়[cite: 1]। | `🔹 ধাপ:` লেবেলসহ হালকা ব্যাকগ্রাউন্ড এবং ব্লু লেফট বর্ডারযুক্ত বক্সে দেখায়[cite: 1]। |
| **`[practice]` / `[prac]`** | ক্লাস অনুশীলন বা মশক/পরীক্ষার জন্য ব্যবহৃত হয়[cite: 1]। | `🎯 মশক / অনুশীলন:` লেবেলসহ ড্যাশড বর্ডারযুক্ত সবুজ হাইলাইটেড বক্সে দেখায়[cite: 1]। |

## বিশেষ ফরম্যাটিং ও স্ট্রাকচারাল রুলস

* **গ্লোবাল সেকশন ব্রেক (`---`):** লাইনের মাঝে একা শুধু `---` ব্যবহার করলে এটি একটি গ্লোবাল সেকশন ডিভাইডার (`<hr class="section-break-divider">`) হিসেবে কাজ করে[cite: 1]।
* **ইনার ব্লক ডিভাইডার (`- - -` বা `***`):** ট্যাগের ভেতরে কন্টেন্ট আলাদা করার জন্য `- - -` বা `***` ব্যবহার করলে সেটি হরিজন্টাল লাইন (`<hr class="lesson-divider">`) হয়ে যায়[cite: 1]।
* **বোল্ড টেক্সট (`**text**`):** লেখার যেকোনো অংশ বোল্ড করতে ডাবল স্টার ব্যবহার করা যায় (`<strong class="lesson-highlight">`)[cite: 1]।
* **সাবটেক্টিভ বা সাবটেক্সট লাইন (`~`):** লাইনের শুরুতে `~` দিলে সেটি নরমাল সাবটেক্সট (`<div class="lesson-subtext">`) হিসেবে স্টাইল পায়[cite: 1]।
* **মেইন লেসন ব্লক:** `[main-lesson]` এবং `[/main-lesson]` ট্যাগ দিয়ে পুরো কন্টেন্টকে মূল লেসন বা টিচিং মেথড হিসেবে আলাদা ক্যাটাগরিতে ট্র্যাক করা যায়[cite: 1]।
